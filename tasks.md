# Collabora Online — O'zbek Tarjima Vazifalar Ro'yxati

## Loyiha haqida

Bu Collabora Online (LibreOffice Online) dasturining O'zbek tilida (lotin va kiril) lokalizatsiya fayllaridir.

### Fayllar joylashuvi (3 ta fayl yangilash kerak):
```
browser/l10n/locore/uz.json         ← O'zbek LOTIN (asosiy)
browser/l10n/locore/uz-Latn.json    ← O'zbek LOTIN (uz.json bilan bir xil)
browser/l10n/locore/uz-cyrillic.json← O'zbek KIRIL
```

### JSON format namunasi:
```json
{
    "Home": "Bosh",
    "Format": "Format",
    "View": "Ko'rinish"
}
```

### Kiril format namunasi:
```json
{
    "Home": "Бош",
    "Format": "Формат",
    "View": "Кўриниш"
}
```
